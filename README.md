# FeedForge

Программа для Windows, которая собирает промо-фиды торговых сетей в один JSON формата Едадил
(`{catalogs, offers, version: 2}`). Источники сети: ссылки, локальные файлы, папки S3; JSON и YML.
Программа отбирает товары (по режиму, цене, охвату магазинов, лимиту), сжимает картинки, загружает результат
на S3 и ведёт историю запусков. Отдельно есть локальная выгрузка в Excel с картинками.

## Сборка

    dotnet publish -c Release

Готовый `FeedForge.exe` (один файл, .NET внутри) лежит в `bin\Release\net8.0-windows\win-x64\publish\`.

## Быстрый старт

1. **Настройки → S3.** Два входящих подключения (только чтение, второе необязательно: пустой бакет значит «не используется»)
   и одно исходящее: бакет, куда загружаются JSON и картинки.
2. **+ Сеть** или **Сети из S3** (по сети на каждую папку бакета): название, имя папки латиницей, источники.
3. На вкладке **Настройки** сети выберите режим сборки, лимит и загрузку на S3.
4. Нажмите **Анализ сети**: программа подскажет настройки. Потом **Предрасчёт**: он покажет результат при ваших настройках.
5. **Старт** собирает JSON и загружает его.

## Кнопки

| Кнопка | Что делает |
|---|---|
| **Старт** | Собирает JSON по настройкам сети и загружает на S3 (или сохраняет локально). |
| **Предрасчёт** | То же, но ничего не записывает и не загружает. Показывает, сколько будет офферов и каталогов, сколько картинок надо загрузить, размер файла, цены и охват. |
| **Анализ сети** | Читает все файлы без ваших фильтров и выдаёт отчёт с рекомендациями по настройкам (см. ниже). Ничего не записывает. |
| **JSON → Excel** | Открывает окно настроек Excel, затем собирает Excel с картинками локально (см. ниже). |
| **Стоп** | Останавливает текущий запуск. |

Вкладки: **Настройки** (сети), **Источники**, **История** (запуски), **Ошибки** (причины и что делать), **Журнал** (подробный ход работы).

## Как работает сборка

1. **Источники и кэш.** Файлы по ссылкам и из S3 скачиваются в кэш. Если файл не менялся, повторно он не скачивается.
   Программа проверяет свежесть фидов: если фид «старый», то спросит, конвертировать ли (настраивается).
2. **Чтение.** JSON читается потоком в два прохода: сначала каталоги (магазины, регионы), потом офферы.
   Товар определяется только по названию (`description`): одинаковые названия в разных магазинах — один товар.
3. **Ошибки в данных.** Некорректные офферы исключаются сразу при чтении и вообще не участвуют в подсчётах
   (ни в числе товаров, ни в ценах, ни в охвате). В журнале пишется их количество по причинам:
   - нет или пусто: `description`, `id`, `image`, `url`, `price_new`;
   - `price_new` не больше нуля;
   - оффер не указан ни в одном каталоге (если в файле каталоги есть);
   - дубль товара в одном каталоге (остаётся первый оффер).
4. **Отбор товаров.** Применяются режим сборки, «Только акционные», охват магазинов, разброс цен, затем лимит (см. ниже).
5. **Картинки.** Берутся только офферы с рабочей ссылкой на картинку. Картинки сжимаются, загружаются на S3 (`<корень>/<сеть>/images/`),
   в JSON подставляются ссылки. Реестр `_images.json` не даёт загружать одну картинку дважды.
   Картинки меньше 400 px можно исключать: при лимите на их место берутся следующие товары (до 5 кругов пересчёта).
6. **Запись и загрузка.** JSON записывается и загружается в `<корень>/<сеть>/<сеть>.json`.
   Локальную копию можно оставлять или удалять (общая настройка).
7. **История.** Каждый запуск записывается: время, режим, результат, количество офферов и каталогов.

## Прогресс выполнения

Под списком сетей показывается панель: полоса прогресса, процент с десятыми долями, сколько прошло времени,
сколько осталось (≈) и во сколько примерно закончится, а также сеть («2 из 5») и текущий этап (последняя строка журнала).
Процент дублируется в заголовке окна, поэтому виден и на кнопке панели задач.

Шкала общая и идёт только вперёд: чтение файлов — первые 40%, дальше картинки (до 65% оставшейся части) и запись JSON.
Оставшееся время считается по ходу работы и сглаживается. Первые секунды и первый процент оно пишет «считаю…».
Оценка приблизительная: этапы разной длины (например, загрузка большого файла на S3 в самом конце) она не знает заранее.

## Режим сборки

- **Как в исходных файлах** (по умолчанию). Каталоги, регионы, цены остаются как в файлах. Фильтры по цене и охвату отключены.
- **Общий каталог для всей России.** Все файлы сети (JSON и YML) собираются в один каталог с target «Россия».
  Один оффер на товар, цена по режиму «Цена» (по умолчанию максимальная), разброс цен и охват магазинов настраиваются.
  Лимит считается на этот единственный каталог.
- **Свои настройки.** Все параметры отбора вручную.

## Настройки сети

**Акции**
- **Только акционные офферы** оставляет только офферы с `price_old`.
- **Сначала акционные**: акционные идут первыми, а если до лимита их не хватает, добираются обычные.
  Эти две галочки взаимоисключающие: пока включена одна, вторая неактивна.

**Файлы и гео**
- **Объединить файлы сети в один результат.** Если у сети 2 и больше файлов, они собираются в один JSON.
  Без неё каждый файл даёт отдельный результат.
- **Гео в JSON:** «Не разбивать» (всё как в файлах), «Только товары, которые есть во всех регионах или магазинах»
  (если регионов нет, «все» считаются по магазинам), «По регионам» (охват и цены считаются в каждом регионе отдельно).
- **Регион — субъект РФ по справочнику** определяет область, край, республику вместо города.
- **Собирать только уникальные товары.** Одинаковые названия и так склеиваются; галочка дополнительно склеивает
  названия, отличающиеся только регистром и пробелами, если у них одна картинка.

**Цена и охват (режимы «Общий каталог» и «Свои настройки»)**
- **Цена:** минимальная, максимальная, средняя или медиана среди цен товара в разных магазинах.
- **Макс. разброс цен, %.** Если цена одного товара в разных магазинах отличается сильнее, товар не берётся.
- **Охват магазинов, %.** Товар должен быть минимум в этой доле магазинов.

**Лимит офферов**
- **На весь результат:** всего не больше N офферов в JSON. Порядок: акционные (если включено «Сначала акционные»),
  затем товары, которые есть в большем числе магазинов, затем стабильный порядок (не меняется от запуска к запуску).
  Товар берётся целиком, со всеми офферами в разных каталогах.
- **На каждый каталог (магазин / регион):** не больше N офферов в каждом каталоге.
- **Один товар может быть в разных каталогах.** Если выключить, каждый товар попадёт только в один каталог.
- Ноль означает без лимита.

**Сроки**
- **Срок действия каталогов, дней** относится к каталогам из ваших JSON: `date_end = date_start + N` (ноль — как в файле).
- **Срок действия каталога «Россия», дней** относится к общему каталогу и YML: период считается от сегодняшней даты.
- **Условия** — текст условий каталога «Россия» (пусто — стандартный).

**S3 и картинки**
- **Загружать JSON на S3** через исходящее подключение.
- **Сжимать картинки и класть на S3**, подставляя ссылки в JSON. Кнопка **Сжатие картинок** задаёт формат, размер, качество и вес
  (по умолчанию JPEG, до 1000 px, качество 85, до 1000 КБ). Те же настройки используются в Excel.
- **Исключать офферы с картинкой меньше 400 px.**

**YML.** Без target все YML вместе дают один каталог «Россия». YML с заданным target (вкладка «Источники» → «Изменить источник…»)
собирается в отдельный каталог; части склеиваются в один JSON.

## Анализ сети и предрасчёт

- **Предрасчёт** отвечает на вопрос «что получится при моих настройках».
- **Анализ сети** отвечает на вопрос «какие настройки подойдут этой сети». Он читает все файлы без фильтров и показывает:
  ошибки в данных; число товаров, офферов, каталогов, магазинов; сколько акций и в скольких каталогах их не хватает до лимита;
  как различается цена одного товара в разных гео; сколько товаров есть в 100/95/80/50% магазинов и при этом с одной ценой;
  сколько офферов в каталогах. В конце идут рекомендации по существующим настройкам: акции, режим сборки, разброс цен,
  охват, лимит, повтор товара между каталогами.

## JSON → Excel

Кнопка открывает окно **Настройки Excel**: разбивка (в том числе по регионам и по магазинам в отдельные папки),
лимит товаров в каждом файле, размер частей и ZIP для картинок. Остальное Excel берёт из основного окна:
цена, разброс, охват, только акционные, уникальные товары, объединение файлов, регион — субъект РФ, сжатие картинок.
Режимы лимита JSON, «Один товар в разных каталогах», сроки каталогов и S3 к Excel не относятся.

## Общие настройки программы

- **Папки:** данных, кэша исходных файлов, результатов (Excel — в папке сети, JSON — в её подпапке `json`).
- **Удалять скачанные исходные файлы после успешной сборки** (иначе повторный запуск не скачивает файл заново, если он не менялся).
  После предрасчёта, анализа или ошибки файлы остаются.
- **Оставлять локальную копию JSON после загрузки на S3.**
- Часовой пояс, число дней, через которое фид считается старым, число потоков скачивания, экономный режим.
- Подключения S3: два входящих (необязательные) и одно исходящее.
